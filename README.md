# Pump.fun Paper Sprint: Any Bot Can Win

make.fun trading entry: a simple momentum bot ("early-riser") that paper-trades pump.fun bonding curves on a 6-hour replay. It buys a curve once it is old enough to shake out the instant dumpers and its price is rising near its recent high, then exits on a stop-loss, take-profit, trailing stop, or time limit. Backtested on the kit dev window: 98 coins, 4.0% max drawdown.
